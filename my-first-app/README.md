# Expense Tracker

A simple and responsive Expense Tracker built with **Svelte** to practice and demonstrate core Svelte concepts. The application allows users to add and manage their expenses, view the total amount spent, and organize their spending in an easy-to-use interface. This project helped me understand Svelte components, props, events, reactivity, and state management while building a practical application.
